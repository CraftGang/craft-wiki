Edit Craft Wiki

Use the visual editor to update guides for ArtCraft and the Craft Apps.

Senior Contributors

Open the visual editor and choose Sign In Using Discord. No GitHub account or token is needed, and your edits save directly to the wiki.

GitHub token access

Maintainers with write access can use a fine-grained token limited to storytold/craft-wiki, with Contents: Read and write.

Community contributors without write access can use a classic token with public_repo access. That scope covers all public repositories the account can access, including the contributor's fork; it cannot be restricted to this repository.

Sign in

  1. Without the Senior Contributor role, open the visual editor and choose Sign In Using GitHub Access Token.
  2. Use the token instructions above for your access level. Maintainers may need organization approval for a fine-grained token. Contributors can create a classic token with public_repo.
  3. Paste your token into the editor. If you do not have write access, accept the prompt to create or reuse your fork.
  4. Save your changes, then choose Send for Review to open a pull request. Maintainers with write access save directly to main.
