Edit Craft Wiki

Use the visual editor to update guides for ArtCraft and the Craft Apps.

GitHub token access

Your fine-grained personal access token needs access only to storytold/craft-wiki, with repository permission Contents: Read and write. Your GitHub account must also have write access to that repository.

The editor currently saves directly to main. It does not create a pull request or grant repository access. Contributors without write access can propose changes through a GitHub fork and pull request.

Sign in

  1. Open the visual editor and choose Sign in with token.
  2. Follow its GitHub token link. Under repository access, select Only select repositories and choose storytold/craft-wiki.
  3. Set Contents to Read and write, generate the token, and paste it into the editor. Your organization may need to approve the token.
