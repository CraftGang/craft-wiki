WordCraft works with the [Zotero](https://www.zotero.org) desktop app: you get Zotero's own citation dialog, all of its citation styles, and a bibliography that updates itself. There's nothing to install in Zotero. It only needs to be running.

## Add a citation

1. Open Zotero.
2. In WordCraft, put the cursor where the citation should go.
3. On the **Zotero** tab, click **Add/Edit Citation**.
4. Zotero's citation dialog opens. Search for the source, pick it, and press **Enter**.

The first time, Zotero asks you to choose a citation style for the document.

To change a citation, put the cursor in it and click **Add/Edit Citation** again.

## Add a bibliography

Put the cursor where the bibliography should go, usually at the end, and click **Add/Edit Bibliography**. It lists every source you've cited, and updates as you add citations.

## The other buttons

| Button | What it does |
| --- | --- |
| **Add Note** | Insert a Zotero note |
| **Refresh** | Update every citation and the bibliography, for example after editing a source in Zotero |
| **Document Preferences** | Change the citation style or language, or switch between footnotes and in-text citations |
| **Unlink Citations** | Turn citations into plain text. They no longer update. Do this only on a final copy |

Switching between in-text citations and footnotes in **Document Preferences** moves the citations for you.

**Move Past Citation** moves the cursor to just after the citation it is in. Read Aloud skips citations and the bibliography.

## Work with Word users

WordCraft stores citations the same way Word's Zotero plugin does. You can pass a document back and forth with someone using Word, and Zotero keeps working for both of you.

## Limits

- In **Document Preferences**, keep the default field type. The **Bookmarks** option isn't supported.
- The web version can't connect to Zotero.
- On a computer shared with other people, WordCraft can only check on Linux that the program it connects to is your own copy of Zotero. On Windows and macOS, keep Zotero running while you use it.
