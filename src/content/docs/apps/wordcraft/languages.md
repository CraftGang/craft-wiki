English spelling and grammar work as soon as you install WordCraft. For other languages, install a **Language pack**: a language's spelling dictionary and hyphenation rules, installed together.

There are Language packs for 75 languages, including Dutch, German, Danish, Swedish, Norwegian, Hungarian, Estonian, Croatian, Persian and Esperanto.

## Install a language

- **From the document**: when your document has text in a language that isn't installed, a bar under the ribbon says so, for example *Dutch proofing isn't installed.* Click **Install**. The button shows the download size.
- **From Options**: choose **File › Options › Language**. **Your languages** lists English, the languages in your document and the packs you've installed. Click **Install** next to a language, or **Add a language…** to search for another one by name or code (for example *dutch*, *nederlands* or *nl*).

The language is checked as soon as the pack is installed, with no restart.

WordCraft doesn't download anything until you click **Install**, **Add a language…** or **Refresh**. Each pack is checked against a known checksum before it's used.

Packs are shared with the other Craft apps, so you only install a language once.

## Remove a language, or make it the default

In **File › Options › Language › Your languages**, click **Remove** next to a pack to uninstall it. Click **Set as default** to make it the language of new blank documents.

## Mark text as another language

WordCraft checks each piece of text in its own language. Select the text, then choose **Review › Language**. The status bar shows the language at the cursor.

If it shows **(no dictionary)**, that language isn't installed yet. If it shows **(dictionary unreadable)**, WordCraft found a dictionary but couldn't use it; point at it to see why.

## Use your own dictionary

You can use any standard Hunspell dictionary (an `.aff` and a `.dic` file), such as one from LibreOffice. Put both files in the **Dictionaries folder** shown in **File › Options › Language**, then restart WordCraft. Your own dictionary is used before an installed pack.

## Change the interface language

WordCraft's menus and buttons come in 27 languages. By default it follows your system's language. To choose another, go to **File › Options › Language**.

## In the web version

The web version checks English only. It has no Language packs.
