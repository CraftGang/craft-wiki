Craft Wiki is the official documentation site for ArtCraft Studio and the Craft Apps. ArtCraft runs it.

The wiki has guides for each app: an overview, getting started, installing and updating, common workflows, and troubleshooting. Some guides are still early drafts and will grow over time.

## Who writes the guides

The ArtCraft team and trusted community members write the guides. Anyone with the **Senior Contributor** role in the ArtCraft Discord server can edit them in the wiki editor. Other contributors can suggest changes through GitHub, and ArtCraft reviews each one before it goes live.

Every change is kept in the site's public [GitHub repository](https://github.com/storytold/craft-wiki), so the history of each page is open to see.
